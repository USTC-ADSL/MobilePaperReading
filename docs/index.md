# 论文共读

这里记录小组共同阅读的论文、讨论和可复用的研究想法。

## 开始阅读

进入左侧的 **论文阅读**，按论文浏览笔记。每篇笔记都可以继续补充，适合记录第一次阅读、组会讨论和后续复盘。

## 添加一篇论文

编辑者可以打开 [内容管理后台](/admin/)，登录后选择 **论文阅读 → 新建论文阅读**。发布后页面会自动更新。

## 我们的阅读方式

1. 先写清楚论文要解决的研究问题。
2. 分别记录方法、证据和自己的疑问。
3. 在讨论问题中留下下一次组会可以直接使用的问题。
4. 用标签把相关论文串起来，持续回看结论是否成立。
